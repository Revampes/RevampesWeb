# RevampesWeb

A modern, responsive personal portfolio website built with HTML, CSS, and JavaScript.
Showcases projects, skills, and contact information with interactive effects and a custom animated particle background.

## Features

- **Single-page style navigation** with smooth transitions
- **Animated particle background** that reacts to mouse movement
- **Custom loader animation** (hamster wheel)
- **Responsive design** for desktop and mobile
- **Project gallery** with dynamic content
- **Contact and about pages**
- **Vanilla JS, no frameworks**

## Folder Structure

```
RevampesWeb/
│
├── index.html                # Home page
├── assets/
│   ├── css/                  # All CSS files (global, page-specific, components)
│   ├── images/               # Images and icons
│   ├── javascript/           # All JS files (page logic, utilities, particles)
│   └── pages/                # All sub-pages (about, projects, contacts, etc.)
│
└── README.md
```

## How to Run

1. **Clone or download** this repository.
2. Open `index.html` in your browser.
3. Navigate using the menu to explore About, Projects, Equipments, and Contacts.

No build step or server is required—everything runs in the browser.

## Customization

- Update your info in `about.html` and `contacts.html`.
- Add new projects in `assets/pages/project.html` and update `assets/javascript/project.js`.
- Change images in `assets/images/`.
